# TABLE-RESERVATIONS: полный гайд по моделям и данным

Архитектура моделей, DTO и их использование.

## 1. Общая архитектура данных

### Уровни данных в системе

1. **HTTP API слой** — данные, которые приходят с клиента.
   - `ReservationInfo` (`Models/`)
   - входной JSON:

   ```json
   {
	 "TablesId": "1,2,3",
	 "CustomerName": "Иван",
	 "CustomerPhone": "+77770000",
	 "ScheduledAt": "25/12/2024 19:30",
	 "Section": "VIP",
	 "RemindBeforeHour": true
   }
   ```

2. **Внутренний слой** — обработка внутри приложения.
   - `TableInfo` — информация о столах
   - `ReminderCandidate` — данные для отправки напоминаний
   - `Constants/` — конфигурация, форматы, статусы

3. **Внешние системы** — POS, Google Sheets, WhatsApp.
   - `CreateReservationRequest` — преобразованные данные для POS
   - `CreateOrderRequest` — преобразованные данные для заказов
   - `ReservationResult` — результат операции из POS
   - `OrderResult` — результат операции из POS

Краткая цепочка:

`Клиентский JSON -> ReservationInfo -> внутренние модели/константы -> модели интеграций`

## 2. Основные модели (`Models/`)

### ReservationInfo

```csharp
namespace table_reservations.Models
{
	public class ReservationInfo
	{
		public string TablesId { get; set; }              // "1" или "1,2,3"
		public string CustomerName { get; set; }          // "Иван Петров"
		public string CustomerPhone { get; set; }         // "+77770000000"
		public string ScheduledAt { get; set; }           // "25/12/2024 19:30"
		public string Section { get; set; }               // "VIP" или "Обычный"
		public bool RemindBeforeHour { get; set; }        // отправить напоминание?
	}
}
```

**Где используется:**
- `Controllers/ReservationsController.cs`
  - `CreateReservation([FromBody] ReservationInfo request)` — получает JSON от клиента, парсит и валидирует.
- `Services/IGoogleSheetsService.cs`
  - `AppendReservationAsync(ReservationInfo reservation, ...)` — сохраняет в Google Sheets.
- `Services/IWhatsAppNotificationService.cs`
  - `SendReservationNotificationsAsync(ReservationInfo reservation, ...)` — отправляет уведомление в WhatsApp.
- `Helpers/ReservationMapper.cs`
  - `ToCreateReservationRequest(ReservationInfo info, ...)` — преобразует для отправки в POS.

**Примечания:**
- Это DTO, который получает данные с HTTP.
- Используется для валидации входящих данных.
- Преобразуется в другие форматы для разных систем.
- Всегда приходит как JSON от клиента.

### TableInfo

```csharp
namespace table_reservations.Models
{
	public class TableInfo
	{
		public int Id { get; set; }                       // ID стола (1, 2, 3, ...)
		public TableType Type { get; set; }               // Enum: Обычный, VIP
		public int Seats { get; set; }                    // Вместимость (2, 4, 6, ...)
		public string Status { get; set; }                // "free", "occupied", "limited"
		public double? NextReservationHours { get; set; } // Часов до следующей брони
	}
}
```

**Где используется:**
- `Controllers/TablesController.cs`
  - `GetTables()` — возвращает список всех столов.
  - `GetTableAvailability(int tableId)` — проверяет занятость.
- `Services/IGoogleSheetsService.cs`
  - `GetTablesAsync()` — возвращает `List<TableInfo>` и читает диапазон `Столики!A2:C100`.
- `Controllers/ReservationsController.cs`
  - `CreateReservation()` — использует для проверки доступности.
- `Helpers/ReservationMapper.cs`
  - `ToTable(TableInfo info)` — преобразует для API.
  - `ToTableList(IEnumerable<TableInfo> tables)` — маппирует в формат POS.

**Примечания:**
- Источник данных: Google Sheets или POS-система.
- Используется для проверки доступности при бронировании.
- Возвращается клиенту в `GET`-запросах.
- `Status` всегда используется для определения занятости.

## 5. Поток данных: примеры

### Сценарий 1: клиент делает бронь

1. Клиент отправляет `POST /api/reservations`.

   ```json
   {
	 "TablesId": "1,2",
	 "CustomerName": "Иван",
	 "CustomerPhone": "+77770000000",
	 "ScheduledAt": "25/12/2024 19:30",
	 "Section": "VIP",
	 "RemindBeforeHour": true
   }
   ```

2. `ReservationsController.CreateReservation()` получает `ReservationInfo` и валидирует:
   - заполненность данных;
   - формат даты через `ReservationDateTime.TryParse()`;
   - время не раньше, чем текущее + 5 минут;
   - попадание в рабочие часы (`12:00 - 04:00`);
   - существование стола;
   - отсутствие конфликта по брони.

3. `_sheets.AppendReservationAsync(request, scheduledAt)` сохраняет запись в Google Sheets (`Брони!A:H`).
4. `_sheets.GetTablesAsync(scheduledAt)` получает `TableInfo`, чтобы построить `typeLabel` (`VIP` или `Обычный`).
5. `_whatsApp.SendReservationNotificationsAsync()` отправляет сообщения клиенту и администратору.
6. Контроллер возвращает `OK`-ответ.

**Цепочка моделей:**

`JSON -> ReservationInfo -> DateTime -> TableInfo[] -> Google Sheets -> WhatsApp`

### Сценарий 2: фоновый сервис отправляет напоминание

1. `ReservationReminderService.ExecuteAsync()` запускается каждые 5 минут.
2. `sheets.GetReminderCandidatesAsync()` читает `Брони!A:H`, фильтрует записи примерно за 60 минут до брони и возвращает `ReminderCandidate[]`.
3. Каждый `ReminderCandidate` содержит:
   - `SheetRowNumber` — строку для обратного обновления;
   - `CustomerPhone`;
   - `CustomerName`;
   - `ScheduledAt`;
   - `ReminderSentCell` — например, `H5`.
4. Для каждого кандидата:
   - `_whatsApp.SendReminderBeforeHourAsync(reminder, ...)` отправляет сообщение;
   - `sheets.MarkReminderSentAsync(sheetRowNumber)` помечает запись как отправленную.

**Цепочка моделей:**

`Google Sheets -> ReminderCandidate[] -> WhatsApp -> Google Sheets`

### Сценарий 3: получить доступные столы

1. Клиент вызывает `GET /api/tables?scheduledAt=25/12/2024 19:30`.
2. `TablesController.GetTables()` парсит `scheduledAt`, если параметр передан.
3. `_sheets.GetTablesAsync(scheduledAt: targetTime)` читает `Столики!A2:C100` и создаёт `TableInfo` для каждой строки.
4. Если время указано, сервис проверяет брони и обновляет `Status` на `occupied`, когда стол занят.
5. Клиент получает JSON-массив столов.

Пример одной записи:

```json
{
  "id": 1,
  "type": "Обычный",
  "seats": 4,
  "status": "free",
  "nextReservationHours": 2.5
}
```

**Цепочка моделей:**

`HTTP query -> DateTime -> Google Sheets -> TableInfo[] -> JSON`

### Сценарий 4: интеграция с POS (HORECO)

1. `ReservationInfo` приходит из HTTP или Google Sheets.
2. `ReservationMapper.ToCreateReservationRequest(...)` преобразует входную модель в `CreateReservationRequest`.
3. `PosAdapterFactory.CreateAdapter(providerName)` выбирает нужный адаптер (`IIKO`, `Paloma`, `r_keeper`).
4. `adapter.ReserveTableAsync(createReservationRequest)` отправляет данные в POS API.
5. POS возвращает `ReservationResult`.
6. `ReservationMapper.IsOperationSuccessful(result)` проверяет успех, после чего можно сохранить внешний ID и отправить уведомления.

**Цепочка моделей:**

`ReservationInfo -> CreateReservationRequest -> POS API -> ReservationResult -> дальнейшая обработка`

## 7. Маппирование и трансформации

`ReservationMapper` — центральная точка преобразований.

- `ReservationInfo -> ToCreateReservationRequest() -> CreateReservationRequest`
- `TableInfo[] -> ToTable() / ToTableList() -> Table[]`
- `ReservationInfoDto -> ToReminderCandidate() -> ReminderCandidate`
- `ReservationResult -> IsOperationSuccessful() -> bool`
- `List<ReservationInfoDto> -> ToReminderCandidates() -> ReminderCandidate[]`

### Почему маппирование важно
- разные системы используют разные форматы;
- `Google Sheets != POS != HTTP API`;
- маппер выступает адаптером между слоями;
- изменения в одной системе не должны ломать другую.

### Пример 4: создать адаптер для новой POS-системы

```csharp
// 1. Создайте класс, наследующий от IPosAdapter
public class MyPosAdapter : IPosAdapter
{
	public string ProviderName => "MyPOS";

	public async Task<ReservationResult> ReserveTableAsync(
		CreateReservationRequest request,
		CancellationToken ct = default)
	{
		try
		{
			var response = await _http.PostAsJsonAsync(
				"https://mypos-api.com/reservations",
				new {
					restaurant = request.RestaurantId,
					customer = request.Customer.Name,
					phone = request.Customer.Phone,
					datetime = request.ReservationTime,
					guests = request.GuestsCount,
					table = request.TableId
				},
				ct
			);

			var result = await response.Content.ReadAsAsync<dynamic>(ct);

			return response.IsSuccessStatusCode
				? new ReservationResult(
					Success: true,
					ExternalReservationId: result.reservationId,
					ErrorMessage: null)
				: new ReservationResult(
					Success: false,
					ExternalReservationId: null,
					ErrorMessage: result.error);
		}
		catch (Exception ex)
		{
			return new ReservationResult(
				Success: false,
				ExternalReservationId: null,
				ErrorMessage: ex.Message);
		}
	}

	// ... остальные методы ...
}
```
